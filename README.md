# Sawdagar Dokanpat

A non-commercial marketplace demonstration inspired by the independent makers and merchants of Bangladesh.

**Demo store: sandbox payments.** This is a portfolio project, not a real shop; no real money is accepted.

## Current state

Phase 0 is establishing the workspace, automated quality checks, and first page. See the [project state](docs/PROJECT_STATE.md) and [roadmap](docs/spec/05-roadmap.md).

## Quality checks

CI runs lint, type checking, unit tests, and a production build on Linux, Windows, and macOS. See [testing](docs/TESTING.md) and [deployment](docs/DEPLOYMENT.md).

## Known limitations

The marketplace, demo data, accounts, payments, language switcher, and dark theme have not been implemented. The current page is static and its English and Bangla text appears together. No live deployment is verified yet.
